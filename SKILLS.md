# Skills для проекта

Установи все команды ниже перед началом разработки.

## Установка

```bash
npx skills add shadcn/ui@shadcn -g -y
npx skills add vercel-labs/agent-skills@vercel-react-best-practices -g -y
npx skills add wshobson/agents@nextjs-app-router-patterns -g -y
npx skills add secondsky/claude-skills@tailwind-v4-shadcn -g -y
```

## Что дают

| Skill | Installs | Зачем |
|-------|----------|-------|
| `shadcn/ui@shadcn` | 129K | Официальный shadcn — как добавлять компоненты, паттерны использования |
| `vercel-labs/agent-skills@vercel-react-best-practices` | 380K | React + Next.js + Vercel best practices от Vercel |
| `wshobson/agents@nextjs-app-router-patterns` | 16K | App Router: RSC, layouts, routing, data fetching |
| `secondsky/claude-skills@tailwind-v4-shadcn` | 3.9K | Tailwind v4 + shadcn вместе — точный стек проекта |
