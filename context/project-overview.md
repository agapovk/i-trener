# Я:Тренер — Project Overview

## Продукт

**Я:Тренер** (i-trener.ru) — медиаплатформа и база знаний для тренеров по футболу на русском языке. Агрегирует статьи, интервью, профили экспертов.
---

## Цели

1. Дать тренерам доступ к качественным профессиональным материалам на русском языке.
2. Сформировать сообщество экспертов и создать площадку для обмена знаниями.
3. Обеспечить удобный поиск и фильтрацию контента по специализациям.
4. Переехать с Webflow на современный стек (Next.js + Vercel) без потери контента.

## Категории контента

- **Менеджмент** — управление клубами, командами, тренерским штабом
- **Профессиональный футбол** — тактика, методика, опыт профи
- **Физическая подготовка** — кондиционирование, нагрузка, восстановление
- **Вратари** — специфика подготовки вратарей
- **Аналитика** — видеоанализ, данные, метрики
- **Детско-юношеский футбол** — ДЮСШ, академии, работа с детьми
- **Психология** — психологическая подготовка, мотивация

---

## Типы контента

### Материалы (articles/materials)
Образовательные статьи. Frontmatter: `title`, `category`, `author`, `date`, `excerpt`, `image`.

### Интервью (interviews)
Развёрнутые интервью с тренерами и специалистами. Frontmatter: `title`, `guest`, `date`, `excerpt`, `image`.

### Профили экспертов (experts)
Карточки экспертов платформы: биография, специализация, ссылки. Frontmatter: `name`, `role`, `specializations[]`, `bio`, `image`, `social{}`.

## MVP — Scope

### В рамках MVP

- Статический сайт с контентом в MDX-файлах
- 3 типа контента: материалы, интервью, эксперты
- Фильтрация материалов по категориям
- Страницы партнёров и контактов
- SEO-метаданные (Open Graph, sitemap)
- Адаптивный дизайн (mobile + desktop)

---

## Критерии успеха MVP

1. Все материалы с i-trener.ru перенесены и доступны.
2. Сайт работает на i-trener.ru через Vercel + custom domain.
3. Pagespeed Insights — 90+ по всем метрикам.
4. Контент можно добавлять через MDX-файлы без кода.
